printer-apology writes one line to a text file: an apology note from an office printer to the people who keep jamming it, feeding it cheap paper and swearing at it. The line was picked from 36 candidates by pairwise judging against the brief — a real apology carrying the printer's own grievance, built on a specific printer truth (a jam on a 200-page thesis), with the punch on the last words.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 103 characters, a single sentence, and ends on its strongest beat. The program holds the line as one constant and checks it against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
